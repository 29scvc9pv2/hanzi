# Hànzì

Web app (PWA) pour apprendre quelques caractères chinois simplifiés par jour : ordre des traits, tracé au doigt, audio, répétition espacée. Fonctionne hors ligne.

Ouvrir dans Safari sur iPhone puis Partager › « Sur l'écran d'accueil ».

Ordre des traits : [Hanzi Writer](https://hanziwriter.org) (MIT), données [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) (© Arphic Technology, Arphic Public License).
